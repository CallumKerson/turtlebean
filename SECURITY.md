# Security policy

turtlebean parses ledger files that may come from other people, so bugs that
let a crafted file crash the parser, hang it or use unbounded memory matter.

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/CallumKerson/turtlebean/security/advisories/new),
not in a public issue. Only the latest version on `main` is supported until
the first release.
