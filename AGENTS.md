# AGENTS.md

## Project

turtlebean is a Rust library that parses and losslessly writes a subset of the
beancount v3 plain-text accounting format. Its first user is `spheres`, a
private personal-finance app, but it's public and must stay general within its
subset. See the README for the goals and the supported subset.

## Commands

```sh
mise run test       # cargo nextest
mise run fix-all    # fix lint and formatting
mise run check-all  # every linter via hk: clippy, rustfmt, cargo-deny, ...
```

Run cargo through mise (`mise exec -- cargo ...` outside an activated shell).

## Rules

- **Clean-room.** Never read, copy, port or paraphrase code from Python
  beancount (GPL-2.0), rustledger (GPL-3.0) or other copyleft
  implementations, including their grammars and tests. Work from the beancount
  documentation and published specifications only. If you need to know how
  beancount behaves, run it and observe the output.
- **Reject, don't guess.** Syntax or semantics outside the supported subset
  produce a clear error with a source position.
- **Lossless.** Parsing then writing an unchanged ledger reproduces it byte for
  byte. Keep source positions and trivia (comments, blank lines, spacing) in
  the syntax tree.
- **Match beancount.** For anything in the subset, balances and errors must
  agree with Python beancount. Add a comparison test for every semantic rule.
- **Test data.** Commit only test files written for this repo or generated by
  `bean-example`. Fetch third-party corpora at test time into `tests/corpus/`
  (gitignored).
- Use plain functions and data-only structs and enums. Keep dependencies few,
  with MIT-compatible licences (`deny.toml` enforces this).
- Use British English in code, comments and docs.
- Pin GitHub Actions by commit SHA and give each job the least permissions.
- Tool config lives in `.config/`, apart from `.typos.toml`, `.oxfmtrc.json`
  and `deny.toml`, which their tools only read from the root.
